## UI / product visual direction

The Statify application must be:
- impeccable
- fresh and distinctive
- exciting and interactive
- premium and polished
- responsive
- clearly branded and immediately recognizable
- substantially more refined than a generic AI-generated dashboard

The primary Statify visual system uses the exact **green + orange + white** relationship established by the approved Sammy master artwork. Do not replace it with an approximate or newly invented palette.

The master character artwork is the source of truth for Sammy/Sandy character presentation, visual language, palette relationship, and brand energy. Character identity and established design must not be casually redesigned.
